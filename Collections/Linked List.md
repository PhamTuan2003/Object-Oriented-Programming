| Basics of Linked List:                                                                                                                                                                                                                                                                                                                                                                                                     | Singly Linked List<br>Double Linked List<br>Circular Linked List                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|                                                                                                                                                                                                                                                                                                                                                                                                                            | `LinkedList là một cấu trúc dữ liệu dạng danh sách, trong đó các phần tử (gọi là các node) được liên kết với nhau thông qua các con trỏ. Mỗi node trong LinkedList chứa hai phần: dữ liệu (giá trị) và con trỏ (hoặc tham chiếu) tới node tiếp theo trong danh sách. Dưới đây là một số khái niệm cơ bản về LinkedList:`                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                                                                                                                                                                                                                                                                                                                                            | **Cấu trúc của LinkedList**<br><br>Mỗi node trong LinkedList có hai thành phần:<br><br>- **Dữ liệu (Data)**: Chứa giá trị của phần tử hiện tại.<br>- **Con trỏ (Next)**: Trỏ đến phần tử tiếp theo trong danh sách. Nếu node này là phần tử cuối cùng thì con trỏ này sẽ có giá trị `null`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|                                                                                                                                                                                                                                                                                                                                                                                                                            | **Các loại LinkedList**<br><br>- **Singly LinkedList**: Mỗi node chỉ chứa con trỏ tới node kế tiếp.<br>- **Doubly LinkedList**: Mỗi node có hai con trỏ, một trỏ tới node trước đó và một trỏ tới node kế tiếp.<br>- **Circular LinkedList**: LinkedList mà node cuối cùng trỏ ngược lại về node đầu tiên thay vì trỏ tới `null`.                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|                                                                                                                                                                                                                                                                                                                                                                                                                            | **Các thao tác cơ bản trên LinkedList**<br><br>- **Thêm phần tử (Insertion)**: Có thể chèn phần tử ở đầu, cuối hoặc giữa danh sách.<br>    - Thêm ở đầu: Đặt con trỏ của node mới trỏ tới node hiện tại đầu danh sách, rồi cập nhật node đầu.<br>    - Thêm ở cuối: Tìm node cuối cùng, sau đó đặt con trỏ của node cuối trỏ tới node mới.<br>- **Xoá phần tử (Deletion)**: Có thể xoá node ở đầu, cuối hoặc giữa danh sách.<br>    - Xóa ở đầu: Cập nhật node đầu thành node tiếp theo.<br>    - Xóa ở cuối: Tìm node áp chót và đặt con trỏ của nó trỏ tới `null`.<br>- **Tìm kiếm (Search)**: Duyệt qua từng node để tìm phần tử với giá trị mong muốn.<br>- **Duyệt danh sách (Traversal)**: Duyệt qua các node từ đầu tới cuối bằng cách đi theo các con trỏ `next`. |
|                                                                                                                                                                                                                                                                                                                                                                                                                            | **Ưu và nhược điểm của LinkedList**<br><br>- **Ưu điểm**:<br>    - **Tính linh hoạt trong kích thước**: Không cần kích thước cố định như mảng.<br>    - **Thao tác thêm và xoá nhanh**: Việc thêm hoặc xoá phần tử ở đầu hoặc cuối nhanh hơn mảng vì không cần phải dịch chuyển các phần tử.<br>- **Nhược điểm**:<br>    - **Tốn bộ nhớ**: Mỗi node cần thêm một con trỏ, tốn thêm bộ nhớ so với mảng.<br>    - **Truy xuất ngẫu nhiên chậm**: Muốn truy cập một phần tử ở vị trí bất kỳ cần phải duyệt qua từ node đầu tiên đến node đó, không truy cập trực tiếp được như mảng.                                                                                                                                                                                         |
