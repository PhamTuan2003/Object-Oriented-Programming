Nó có thể tăng hoặc giảm kích thước một cách linh hoạt khi các phần tử được thêm vào hoặc xóa đi.<br><br>### ArrayList khác với Array trong Java như thế nào?<br><br>> Mảng ArrayListcó thể thay đổi kích thước một cách linh hoạt, trong khi mảng truyền thống có kích thước cố định. ArrayListcũng cung cấp nhiều phương thức hữu ích như add(), remove(), và size().<br><br>### Làm thế nào để tạo ArrayList trong Java?<br><br>> ArrayList<String> danh sách = new ArrayList<>();<br><br>### ArrayList có thể chứa các kiểu dữ liệu nguyên thủy như int hoặc char không?<br><br>> Không, ArrayListchỉ có thể chứa các đối tượng. Bạn phải sử dụng các lớp bao bọc như Integer hoặc Character.<br><br>### Làm thế nào để thêm các phần tử vào ArrayList?<br><br>> Chúng ta có thể thêm các phần tử bằng add()phương pháp:list.add(“Xin chào”);<br><br>### Làm thế nào để truy cập các phần tử trong ArrayList?<br><br>> Có thể truy cập các phần tử bằng get()phương pháp:Phần tử chuỗi = list.get(0);<br><br>### Làm thế nào để xóa một phần tử khỏi ArrayList?<br><br>> Sử dụng remove()phương pháp để xóa các phần tử theo chỉ mục:danh sách.xóa(0);<br><br>### ArrayList có được đồng bộ hóa không?<br><br>> Không, ArrayListkhông được đồng bộ hóa.
```java
// Java Program Example to Demonstrate
// Addition, Deletion and Updation of Element
import java.util.*;

class Main {
    public static void main(String args[]){
      
        // Creating an Array of string type
        ArrayList<String> al = new ArrayList<>();
      
          // 1. Addition

        // Adding elements to ArrayList
        // at the end
        al.add("Geeks");
        al.add("Geeks");

          System.out.println("Orignal List : "+al);
          
          // Adding Elements at the specific
          // index
        al.add(1, "For");

          System.out.println("After Adding element at index 1 : "+ al);
          
          // 2. Deletion of Element
          
          // Removing Element using index
          al.remove(0);
      
          System.out.println("Element removed from index 0 : "+ al);
          
          // Removing Element using the value
          al.remove("Geeks");
      
          System.out.println("Element Geeks removed : "+ al);
      
          // 3. Updating Values
          
          // Updating value at index 0
          al.set(0, "GFG");
          
      
        // Printing all the elements in an ArrayList
        System.out.println("List after updation of value : "+al);
    }
}

```

OUTPUT
- *Orignal List : [Geeks, Geeks]*
- *After Adding element at index 1 : [Geeks, For, Geeks]*
- *Element removed from index 0 : [For, Geeks]*
- *Element Geeks removed : [For]*
- *List after updation of value : [GFG]*
